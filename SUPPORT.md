# Support

Use [GitHub Issues](https://github.com/hybernia1/portable-developer/issues) for reproducible bugs and feature proposals. Include the Portable Developer version, Windows version, UI language, reproduction steps, and only log lines you have reviewed for private information.

Do not post vulnerabilities, passwords, database contents, private project files, or unreviewed logs in public issues. Report security problems through [GitHub Security Advisories](https://github.com/hybernia1/portable-developer/security/advisories/new).

The project is maintained on a best-effort basis and currently has no paid or guaranteed support channel.
