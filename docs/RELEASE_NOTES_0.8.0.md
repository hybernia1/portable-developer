# Portable Developer 0.8.0

Version 0.8.0 completed the cross-application visual normalization and strengthened Selenium profile enrollment.

## Highlights

- Unified page spacing, tabs, selectors, dialogs, scrollbars, window chrome, and maximized work-area behavior.
- Added profile-name validation before opening a browser, local managed-profile discovery, and clearer enrollment progress.
- Added deterministic app-managed browser environments and stopped relying on host browser profiles.
- Improved restricted terminal help and safe filesystem operations.
- Added consistent Composer/Python package progress and file association behavior.

The release remained portable, self-contained, and unsigned, with no Windows service, registry, system `PATH`, hosts-file, or firewall changes.
