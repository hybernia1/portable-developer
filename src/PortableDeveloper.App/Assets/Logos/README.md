# Technology logos

The transparent SVG marks in this directory are sourced from the [Simple Icons](https://github.com/simple-icons/simple-icons) catalog. They are used only to identify the installed technologies in the Portable Developer interface.

Simple Icons publishes the catalog under CC0-1.0, but the marks remain subject to their owners' trademark and any individual licensing conditions. The source URLs and available license information are maintained in the Simple Icons catalog data.

Included marks: Apache, Composer, Firefox, Google Chrome, MariaDB, Notepad++, PHP, phpMyAdmin, Python, and Selenium.
