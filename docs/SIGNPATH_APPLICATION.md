**Tagline**

A transparent, portable local web-development environment for Windows that keeps its services, tools, projects, and configuration inside one folder.

**Description**

Portable Developer is a GPL-licensed Windows desktop application for running an isolated local development environment from a normal folder or external drive. Users explicitly choose the web, database, browser-automation, and language tooling they need. The application does not install Windows services or modify the system PATH, registry, file associations, hosts file, or firewall. Its public build and dependency provenance are designed to be auditable.

**Reputation**

Portable Developer is a newly released independent project, so it does not claim broad adoption, media coverage, or established download statistics. Its verifiable trust evidence is GPL-3.0-or-later source, public Windows CI, more than 150 automated tests, tag-built GitHub Releases with SHA-256 files, pinned upstream sources and hashes, private vulnerability reporting, explicit governance/signing roles, and a release workflow tied to public commits. Repository: <https://github.com/hybernia1/portable-developer>; releases: <https://github.com/hybernia1/portable-developer/releases>; build provenance: <https://github.com/hybernia1/portable-developer/actions>. The project's recent creation may require more reputation before approval; usage evidence will be supplied when it exists rather than fabricated.
