# Portable Developer 0.7.0

## Highlights

- Added catalog-managed Selenium browser/driver downloads and immutable profile masters.
- Added shared WPF dialogs, dropdowns, tabs, progress indicators, and custom window chrome.
- Enforced single-instance startup.
- Added safe filesystem commands to the restricted terminal and prepared its command layer for future headless use.
- Added package progress for Composer and Python and Windows file associations with a portable-editor fallback.

The release passed formatting, Release build, automated tests, catalog validation, and unsigned portable packaging checks.
