# Zdrojové projekty

Zde je C# solution vytvořená v milníku M1. Cílí na .NET 10; přesná verze SDK je uvedena v `../global.json`.

Projekty:

- `PortableDeveloper.App` — WPF UI a composition root;
- `PortableDeveloper.Application` — aplikační případy užití;
- `PortableDeveloper.Domain` — modely instancí, modulů a stavů;
- `PortableDeveloper.Infrastructure` — procesy, soubory, ověření modulů, health checky a logování;
- `PortableDeveloper.Tests` — jednotkové a integrační testy.
